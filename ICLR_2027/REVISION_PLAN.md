# ICLR 稿件完整修改方案：理论解释优先，残差修正作为推论

日期：2026-09-13。对象：当前 8 页正文版本。本文档记录研究定位、审稿风险、分阶段工作与验收要求；新增实验和新增理论结果均是待办，不能作为已完成贡献写入论文。

## 1. 修订后的贡献层次

**首要贡献：压缩 LoRA 的偏差—方差理论解释。** 本文研究压缩如何改变统计估计风险，刻画何时移除方差的收益超过投影偏差的代价，以及何时该关系反转。它把低维适配的可行性、表示效率和投影几何，与压缩相对于完整 LoRA 估计器的风险比较联系起来。

**第二贡献：将解释变为条件明确、可以检验的预测。** 给出固定任务的残差能量—噪声阈值、额外平均下的 ensemble 条件，以及有明确正则性假设的样本量预测。沿序列估计、非线性 Transformer、真实微调三个层次区分精确验证、定性证据和代理诊断。

**第三贡献：理论导出的等预算残差修正。** 恢复重要残差会降低投影偏差，但必须计入被替代的压缩容量及支持选择噪声。ProLoSA 将这一原则实例化；方法提升和失败共同检验该设计原则。

三项贡献的逻辑顺序是“统计解释 → 条件与验证 → 设计应用”。不再把全文收缩为一种预算分配方法，也不把两个命题表述成新发现了通用偏差—方差原理。

建议英文中心句：

> We develop a bias--variance account of compressed LoRA that links the statistical benefit of restriction to the estimation variance it removes and the task-relevant projection bias it introduces. This account yields conditions for beneficial and harmful compression and motivates sparse residual correction under a fixed adaptation budget.

## 2. 与已有工作的精确区别

核查的一手文献：

- [Uni-LoRA, NeurIPS 2025](https://proceedings.neurips.cc/paper_files/paper/2025/file/3e596a70b60dcf7c6e0ac1a2d73e7470-Paper-Conference.pdf)：§3.2–3.3 将 LoRA 参数重构统一为投影，并讨论全局性、均匀性与等距性。不能称它只有内在维度直觉而没有理论。
- [FourierFT, ICML 2024](https://proceedings.mlr.press/v235/gao24o.html)：主要依据是傅里叶表示的表达效率，学习少量谱系数重构权重增量。它作用于权重更新空间，不应直接归为 LoRA 因子空间压缩。
- [Aghajanyan et al., Intrinsic Dimensionality, ACL 2021](https://arxiv.org/abs/2012.13255)：包含内在维度与压缩泛化界的联系；不能声称该研究线完全没有泛化分析。

本文可主张的区别：低维表示、投影等距性或一个泛化上界，本身不决定某个实际压缩子空间相对于完整 LoRA 估计器的风险差的符号。本文以该比较为研究对象，将被排除的任务信号、保留的估计噪声和训练数据规模放入一个条件明确的分析中。

可突出的问题：

| 问题 | 本文提供的对象 | 当前证据边界 |
|---|---|---|
| 为什么进一步压缩有时还能更好？ | 移除方差与投影偏差的比较 | 局部近似；真实测量还包括优化随机性 |
| 同一维度为何不保证相同性能？ | 子空间与任务更新的对齐及各向异性噪声 | 控制两项才能归因于对齐 |
| 何时压缩会失效？ | 固定任务能量—噪声阈值及偏差下界 | 精确阈值属于序列模型 |
| 数据增多后优势是否会消失？ | 局部风险差 A/n-B | GLUE 尚未建立可靠 crossover |
| 哪些偏差可被小残差分支修复？ | 等预算下恢复能量与机会成本 | 真实 SNIP 仍需理论或预测性实验加强 |

避免使用“已有工作都只归因于内在维度”“首次解释所有压缩 PEFT”“等距性保证泛化”“全部实验验证完整理论”等表述。

### 4.1 区分统计方差与优化方差

E3 的 CoLA 总方差从 0.0636 降到 0.0332，其中优化方差从 0.0593 降到 0.0326，约占下降量的 88%。正文图应展示“偏差代理、统计方差、优化方差”三个分量，不能将总方差下降直接认定为 A/n 项的验证。

工作：重绘分解图；核对重复样本修正；说明 reference ensemble 的选择；评估替换参考模型是否改变偏差排序。验收：每种随机性来源明确，与样本量模型的关系不混淆。

### 4.2 E1 配对不确定性和拟合

从原始配对种子结果计算风险差置信区间；不能用两组边际标准差虚构配对误差。比较满足 a≥0、b≥0 的 a/n-b 拟合与无约束拟合，报告拟合残差和不确定性。符号不符时不得一概解释为样本量不足。

### 4.3 E5 几何与随机参考

核查欧氏残差再做 Fisher 加权，与 H-投影残差之间的差别。对均匀原始坐标支持，参考能量比例应根据候选集推导；D 个候选坐标时为 K/D，不能直接把残差子空间维数 D-d 当作候选坐标数。实际随机支持采样可直接检验参考分布。验收：诊断量、理论量和基准的差别透明。

## 6. 理论或预测性加强：待研究，不预先宣称

可选择一条最可行路线：

1. 针对 one-hot 参数共享组推导支持选择与实际 H-加权偏差下降的关系，使分析使用实际参数化的结构。
2. 给出支持估计误差或噪声相关选择对收益的界；仅使用全协方差公式不能自动保持条件噪声的无偏性和理想方差公式。
3. 使用独立校准集或早期训练诊断，事先预测任务/预算上的压缩收益或残差分配收益，再在未用于选择的数据上检验。可以首先预测收益排序，不必强求精确 crossover。

第一贡献仍是偏差—方差机制解释。这些加强用于证明该解释给出超出事后归因的知识，而非把理论解释降为方法包装。

## 7. 必须保留的边界

- 固定任务条件使用残差能量；ensemble 条件需要另外的目标生成假设。
- 低维性不保证指定子空间与任务对齐；等距嵌入不消除被排除方向上的偏差。
- FourierFT 与 LoRA 因子压缩作用于不同空间；本文不自动证明对全部方法的统一结论。
- A/n-B 是局部渐近分析；实际优化方差和有限步训练可能产生额外效应。
- 真实 GLUE 尚无可靠 crossover；CoLA 未显示 ProLoSA 偏差修正。
- Fisher 和 reference ensemble 指标是代理诊断，不能代替未知总体风险。
- warmup SNIP 的同数据选择不满足理想支持独立假设。
- 现有数学推理中的负结果和配置选择方式应保留。
