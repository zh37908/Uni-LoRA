## GLUE 预设协议

- 任务：CoLA、MRPC；模型：RoBERTa-large；模块固定为 query/key/value/output.dense/intermediate.dense。LoRA、Uni-LoRA、ProLoSA 的秩均为 4，RoSA 的秩为 2，以在加入稀疏分支后匹配 LoRA r4 的总适配预算。
- 有效适配坐标：LoRA = RoSA = 1,769,472；Uni-LoRA = ProLoSA = 23,040。ProLoSA 分配为 d=22,320、K=720；RoSA 分配为低秩 884,736、稀疏 884,736。分类头共享同一训练规则、另行计数。ProLoSA 当前实现存储稠密掩码向量，因此另报实际分配参数、显存和耗时，不能把 23,040 当作其物理存储量。
- 从原训练集按标签分层固定划出 10% 用于配置和 checkpoint 选择，90% 用于拟合，划分 seed=20260913。原始 GLUE dev 在调参期间不评分；仅对锁定配置的最终 checkpoint 评分一次。最终运行仍使用同一 90% 拟合集，避免调参和最终拟合规模变化。该划分为本轮的前瞻性协议；CoLA/MRPC 的原始 dev 在历史研究中已经使用过，不能称作全新未知测试集。
- 每方法每任务 12 个候选配置：3 档适配学习率 × 4 组正则化/停止设置。LoRA/RoSA 学习率为 1e-4、4e-4、1e-3；Uni-LoRA/ProLoSA 为 1e-3、5e-3、1e-2。分类头学习率从 2e-4、1e-3、5e-3 循环分配，涵盖所有适配 LR 与 head LR 配对，但不做全部超参数的笛卡尔积。
- 正则化/停止组依次为 (WD=0, dropout=0, best)、(.01,.05,best)、(.1,.1,best)、(.01,.05,last)。这是各方法等候选次数的预设搜索，不是每个超参数效应的独立消融。
- 调参种子 101、102；按内部验证分数的两种子均值选配置，同分比较验证 loss、再比较配置编号。选择后写入 `locked_selection.json`，最终种子固定为 201–205。共 192 次调参 + 40 次最终运行。
- 每次 40 epochs、batch size 32。best/last 表示 checkpoint 选择策略，两者均执行相同训练上限；不把 best 误称为实际提前终止训练。
- 混合方法先 warmup 128 步、评分 128 步再激活支持；四种方法都在第 256 步之后才允许 checkpoint 入选。RoSA 使用仓库实现的 mean-squared gradient 支持评分；稀疏学习率固定为对应适配学习率的 0.2 倍。
- `snapshots/glue_driver.py` 是本轮冻结的训练入口，SHA256 为 `79e5615645ade00af7d825ac6cece5fa14d494368a42541730efb7c495cf44f5`。PEFT 后端取自 `NLU/peft/src`，其源文件指纹另存于 `source_manifest.json`。

输出包含各次 heldout score/loss、五种子均值和标准差、配对点态 t 区间、参数/显存/调参及最终训练时间。置信区间条件于固定划分和评估集，反映训练种子变化，不能当作任务总体的不确定性。

## 合成实验预设协议与固定 θ*

代码：`synthetic/revision_controls/run_controls.py`。数据：`synthetic/results_revision5_fixed_teacher/`。这是新增的、源码完整可读的 Transformer 对照，不与历史 Transformer 实验混为同一协议。

- 固定骨干为宽度 64、序列长 32、4 头、FFN 256 的单层 Transformer，先预训练 300 步；适配 q/v 权重的 8,192 个坐标。固定 P、测试输入以及各 profile 的教师和测试真值。
- 两个教师的校准功能位移 MSE 均约为 0.002987907，即固定基模型校准输出方差的 10%。欧氏投影残差最大的 64 个原始坐标分别包含约 99.206% 和 6.854% 的残差能量。这里固定的是功能位移，不要求两教师的参数范数相同。不同教师仍是两个独立的固定问题，不能宣称仅凭这一对教师已隔离所有任务几何差异。
- `teachers.pt` 只准备一次。concentrated 的 target_id 为 `f343dc8618448c0c9d0e37927b8e6f50dc169343e536bdaae4bfce436cb39630`；diffuse 为 `82a8db1d1a8818d5c70195f5dd662c8928cafd785f34afc6223fdd840b5afa83`。每次运行前后核对目标指纹；不随训练种子、噪声或 n 重新采样 θ*。
- 网格：2 个教师 × n∈{64,256,1024,4096} × 噪声标准差∈{.25,.5,1} × 20 种子 = 480 个 trial。相同 n/seed 在不同教师和方法间共享训练输入与标准化噪声；评估使用固定的 1,024 个无噪声测试样本。
- 方法：LoRA r4（1,024 参数）、compressed（128 参数）、random、gradient、snip、energy、snip_independent、snip_same_half（后六者均 d=64、K=64，总计 128）。LoRA 与其余方法的比较是预算折衷；压缩与稀疏混合之间才是等预算。
- 支持质量混合对照采用同一 pilot、选支持后重新初始化最终适配器的协议，属于诊断实验，不冒充原 ProLoSA 端到端训练。梯度评分累计绝对梯度；SNIP 累计 |delta × gradient|；energy 使用固定教师的欧氏投影残差 q_i²，是知道 θ* 的 oracle，而非可部署估计器。
- 每方法计 1,000 个梯度步骤：纯 LoRA/压缩训练 1,000 步，混合方法 pilot 256 步、最终拟合 744 步；pilot 最后 128 步累计评分。AdamW LR=.005、WD=0，batch size=min(128,拟合样本数)。随机和 oracle 对照也收取 pilot 成本；实际复用公共 pilot 的计算节省与每方法独立运行的计费口径要区分。
- 独立选择：A=n/2 样本用于 pilot 和选支持，B=n/2 用于重新初始化后的最终拟合，不传递 A 上的模型参数或优化器状态。总唯一使用数据为 n。
- 等拟合规模对照 snip_same_half：仅用 B 选支持并拟合，选择和拟合规模均为 n/2，总唯一使用数据为 n/2。与独立选择比较时拟合规模一致，但唯一使用数据不同；与全数据 snip 比较则固定总唯一数据 n、拟合规模不同。两个比较一起呈现。
- 每次保留逐样本预测。对每个固定 (teacher,n,noise,method) 的 20 种子分别计算 bias² 和 variance，variance 分母为 20，验证 mean MSE=bias²+variance；不含 1/2。该方差联合包含训练数据、标签噪声、优化种子的变化。拒绝混合 teacher_id；不把两个教师的偏差、方差合成一个任务分解。
- 支持捕获比例是欧氏坐标能量代理；真正的功能风险和偏差来自固定教师预测。保留全部正负结果以及同种子的风险差，不能只挑支持有效的格子。

最终协议为 `pilot_reset_matched_half_v2`，正式输出在 `trials_v2/`。先导运行 `trials/` 在补入等拟合规模对照后停止并保留，**不进入正式汇总**；教师文件保持不变。smoke/smoke_v2 也不进入正式汇总。
